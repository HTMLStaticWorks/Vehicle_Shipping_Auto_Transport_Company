1. Template Overview

ROADLINK AUTO is a commercial-grade HTML5 template engineered specifically for vehicle shipping companies, auto transport brokers, car haulers, and automotive freight logistics operators.

Technology Stack:
  • HTML5 Semantic Markup
  • Bootstrap 5.3.3
  • Bootstrap Icons 1.11.3
  • Vanilla CSS3 (Design Tokens)
  • GSAP 3.12 (Micro-animations)
  • Vanilla JavaScript (Zero heavy frameworks)
Key Highlights:
  • 19 Production-Ready HTML Pages
  • Full Light & Dark Theme Persistence
  • Front-End Tracking Simulation (RL-2026-04821)
  • Multi-Section Interactive Quote Calculator
  • Strict No-Dashboard Compliant Auth UI
  • 100% Responsive from 320px to 2560px+

3. Dark / Light Mode System

Theme switching is managed through CSS custom properties attached to [data-theme="light"] and [data-theme="dark"] in assets/css/style.css.

When a user toggles the theme button, main.js updates the data-theme attribute on <html> and persists the user preference in localStorage.setItem('roadlink_theme', theme). 

/* Example Theme Custom Properties */
:root {
  --color-primary: #1e40af;
  --color-cta: #ea580c;
}

[data-theme="light"] {
  --bg-page: #f8fafc;
  --bg-surface: #ffffff;
  --text-main: #0f172a;
}

[data-theme="dark"] {
  --bg-page: #0b1322;
  --bg-surface: #111c30;
  --text-main: #e2e8f0;
}

4. Navigation Structure

The template includes a sticky responsive header with multi-level dropdowns configured to prevent viewport overflow:

  • Home ▾: Home 1 (Transport Portal), Home 2 (Logistics Control)
  • Shipping Solutions ▾: Nationwide Shipping, Cross-Country, Dealer & Auction, Luxury & Classic, Shipping Process
  • Direct Nav Links: Tracking, Get a Quote, About, Contact, Dashboard
  • Controls & Action Buttons: RTL Mode Toggle, Theme Switcher, Sign Up Button

5. Tracking Simulation Module

The tracking interface supports live simulation for any input or default tracking ID RL-2026-04821. It renders the 6-stage visual pipeline, origin/destination coordinates, driver details, and status updates dynamically without page reload.

6. Quote Calculator Module

The quote form validates required fields (origin, destination, year, make, model, customer contact) using HTML5 and Bootstrap validation classes. On submission, an interactive modal or in-page alert calculates estimated price ranges based on the selected carrier type (Open vs Enclosed).

7. Authentication UI (No Dashboard)

login.html, signup.html, and forgot-password.html are front-end authentication UI demonstrations with real-time field validation and password visibility toggles. In strict accordance with template guidelines, they do not redirect to any client dashboard.

8. GSAP Micro-Animations & Accessibility

Elements marked with .gsap-reveal trigger subtle entrance transitions when scrolling into view via IntersectionObserver. The system automatically honors prefers-reduced-motion: reduce media queries for accessibility compliance.
